# Lane reports

One report per work package ("lane"), named `L<n>-<topic>.md`, written when the lane closed: what was built
or measured, the numbers, what was not done, and the commands that reproduce it. Orders for runs on the phone
are in `orders/`. Ways of working, the placeholders used in the commands (`user@phone`, `<phone-home>`,
`<datasets>`, `<scratch>`) and how root is reached on the phone: [docs/WAYS_OF_WORKING.md](../WAYS_OF_WORKING.md).

Drive recordings, ride videos, frames and models are never committed; a report names a recorded drive by its
session id (`YYYYMMDD-HHMMSS`) only.
